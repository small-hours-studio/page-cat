# Submitting Page Cat — field by field

Open <https://chrome.google.com/webstore/devconsole> in Chrome. Files are relative to the `page-cat` folder.

## 1. Create the item
- Click **New item** and upload `dist/page-cat-0.1.0.zip`.
- The name, icon and the short summary come from the manifest automatically.

## 2. Store listing tab
- **Description:** paste the whole block under "Description" in `store/listing.md`.
- **Category:** Fun (under Lifestyle). If it isn't offered, use Entertainment.
- **Language:** English.
- **Store icon:** `store/icon-store-128.png`
- **Screenshots** (drag in this order): `store/screenshots/1-perch.png`, `2-play.png`, `3-nap.png`, `4-settings.png`
- **Small promo tile:** `store/promo-small.png`
- **Marquee promo tile:** `store/marquee.png`
- **Homepage URL:** `https://tsassypants.github.io/page-cat/`
- **Support URL:** `https://github.com/tsassypants/page-cat/issues`
- **Mature content:** No.
- Click **Save draft**.

## 3. Privacy tab
- **Single purpose:** `Displays an animated cat companion on top of web pages the user chooses.`
- **Permission justifications:** paste each one from "Permission justifications" in `store/listing.md`:
  - storage
  - scripting
  - Host permission (all sites)
- **Are you using remote code?** No.
- **Data usage:** leave every data type unchecked. Tick all three certifications.
- **Privacy policy URL:** `https://tsassypants.github.io/page-cat/privacy.html`
- Click **Save draft**.

## 4. Distribution tab
- **Payments:** Free.
- **Visibility:** Unlisted.
- **Regions:** All regions.
- Click **Save draft**.

## 5. Submit
- Check the Account tab shows a verified contact email.
- Click **Submit for review**. Leave "publish automatically after it passes review" on, unless you want to press Publish yourself.
- Reviews usually take a day to a few weeks. You'll get an email either way.
